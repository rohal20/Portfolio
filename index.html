note #01~1 min read

How I cut incident diagnosis time by up to 90%

Three dashboards, one tired engineer. So I let an LLM agent read them together.

Claude APIPrometheusGrafanaJaeger

The problem

When something breaks you tab-switch between Prometheus (metrics), Grafana (dashboards) and Jaeger (traces) and correlate by eye. It is slow, and it happens at the worst possible time.

The approach

A thin adapter layer normalises each source into one shape, so the agent can reason over metrics and traces together. The Claude API then turns the correlated signals into a plain-English explanation.

The lesson

The model was not the hard part. Clean, comparable inputs were.

note #02~1 min read

Killing the spreadsheet-and-email workflow

Wholesale orders lived in spreadsheets and inboxes. I replaced that with one single-page app.

ReactTypeScriptNode.jsSQL

The problem

Reps were re-typing the same numbers into three systems, and orders could get lost in email threads.

The approach

An internal SPA for catalog, inventory and wholesale orders on top of one integrated API, so every number is entered once.

The lesson
