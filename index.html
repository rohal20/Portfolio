The short
version

I studied Computer Science with a focus on Software Engineering at Brock University, graduating on the Dean's Honor List. Somewhere between coursework and internships, I got hooked on the part most developers skip: what happens to code after it ships.

That's led me toward observability tooling — OpenTelemetry, Prometheus, Jaeger, Grafana — and more recently, using the Anthropic Claude API to build an agent that reads traces and metrics so I don't have to at 2am.

Today I'm a Software Developer I at Pitama Foods in Toronto (remote, from Karachi). Before that, I interned at E Planet Global on products used by 50,000+ people a day.
