# Rohal Kabir — Portfolio

Single-file neo-brutalist portfolio (`index.html`) built with vanilla HTML/CSS/JS and GSAP + ScrollTrigger (loaded from cdnjs).

- Deploy: any static host (Vercel config in `vercel.json`).
- Contact form: set `WEB3FORMS_KEY` in `index.html` (free key from web3forms.com); without it the form opens the visitor's mail client.
- Optional: add `copilot-dashboard.png` or `copilot-demo.mp4` next to `index.html` to show a real screenshot/clip in the AI Copilot case study.
- Keyboard: `Ctrl/⌘+K` command palette, `` ` `` terminal, `?` shortcuts.
